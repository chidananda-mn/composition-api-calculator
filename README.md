# Composition API Calculator

This project is a calculator built using the Composition API in Vue.js. The goal of the project is to demonstrate the features and capabilities of the Composition API while providing a user-friendly calculator interface.

## Features
- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Responsive design for better user experience on various devices
- Clear display of current input and results

## Technology Stack
- Vue.js
- Composition API
- HTML & CSS

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/chidananda-mn/composition-api-calculator.git
   ```
2. Navigate to the project directory:
   ```bash
   cd composition-api-calculator
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the application:
   ```bash
   npm run serve
   ```

## Usage
Open your browser and go to `http://localhost:8080` to use the calculator.
